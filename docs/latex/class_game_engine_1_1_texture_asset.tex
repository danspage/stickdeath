\doxysubsection{Detailed Description}
A single asset used to store a texture in the Texture\+Manager\textquotesingle{}s memory. It will not be directly accessed by the game outside of the Texture\+Manager\textquotesingle{}s internal code, rather it will be used to map texture names to image data within it. In the rest of the game\textquotesingle{}s code, a \href{src/framework/graphics/GameImage.h}{\texttt{Game\+Image}} will be returned when requesting a texture. 

See \href{src/framework/graphics/GameImage.h}{\texttt{Game\+Image}} for the underlying image wrapper.
